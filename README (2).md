## Objetivo

A atividade reúne o levantamento e a classificação de ferramentas CASE, a definição de um toolchain para o semestre e a modelagem de um **Sistema de Empréstimo de Equipamentos do Laboratório** nas visões estruturada e orientada a objetos.

## Ferramentas analisadas

| Ferramenta | Versão | Categoria CASE | Função principal |
|---|---:|---|---|
| draw.io / diagrams.net | Web | Upper CASE | Diagramação |
| StarUML | 7.1.0 | Upper CASE | Modelagem UML |
| MySQL Workbench | 8.0.47 | Upper CASE | Modelagem de dados |
| Visual Studio Code | 1.134.0 | Lower CASE | Codificação |
| Git | 2.55.0.windows.4 | Integrated CASE / gestão de configuração | Controle de versão |
| GitHub | Web / SaaS | Repositório remoto integrado ao Git | Colaboração e repositório |

## Toolchain escolhido

- **StarUML**: análise e projeto orientados a objetos.
- **Visual Studio Code**: construção e implementação.
- **Git**: controle de versão, usando o **GitHub** como repositório remoto.

## Estrutura do trabalho

- **Parte A**: inventário, classificação e justificativa do toolchain.
- **Parte B.1**: DFD nível 0, DFD nível 1 e dicionário de dados.
- **Parte B.2**: diagrama de classes com atributos, métodos, relacionamentos, encapsulamento e herança.
- **Parte B.3**: comparação entre os paradigmas estruturado e orientado a objetos.

## Mini-caso

O laboratório controla empréstimos de notebooks, projetores e kits de robótica para alunos e professores. Alunos podem retirar 1 item por até 2 dias; professores podem retirar até 3 itens por até 7 dias. Devoluções em atraso geram bloqueio de novos empréstimos por 15 dias.
